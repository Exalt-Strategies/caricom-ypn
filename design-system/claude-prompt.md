# Copy-paste prompt for Claude — Caribbean sticker-poster style

> Design in the **Caribbean sticker-poster style**. Rules:
>
> **Palette** (use only these; each adjacent layer a *different* one): ink `#000000`, paper `#ffffff`, signal-red `#ee3835`, cobalt `#007df6`, acid-lime `#c3f900`, spring-mint `#6dff80`, lavender `#bea2e7`, orchid `#e280fd`, lemon `#f8eb39`, kelly-green `#29b24a`, coral `#ffabab`.
>
> **Layering — nested rounded rectangles.** Black page → poster → inner card(s) → photo frame, each a *clashing* solid fill, floating with even gutters so nothing touches the edge. Radius steps DOWN as you nest: outer 44px → card 32px → photo 22px (≈4–5% of element width). A **3px solid black keyline** on every card and poster. Flat fills only — **no gradients, no drop shadows, no glassmorphism**.
>
> **Photos** sit inside a rounded frame with a **thick 12px border** in a color that clashes with both the photo and the card behind it. Never full-bleed. Treat portraits as cutouts on a flat chroma backdrop.
>
> **Type — Inter, heavy.** Headlines/wordmark: weight 800, UPPERCASE, tight (`letter-spacing -0.02em`, `line-height 1.0`), huge, near full width. Body: weight 500, `line-height 1.4`. Labels/eyebrows/pills: weight 800, UPPERCASE, wide `letter-spacing 0.18–0.22em`, small. Callout names can be all-caps **outlined** (bright fill, e.g. coral, + 3px black text-stroke).
>
> **Text color:** ink (black) on every fill EXCEPT the dark backdrops (cobalt, signal-red, kelly-green), where it flips to paper (white).
>
> **Components:** pills (ink bg, paper text, 2px ink border, radius 999); CTA pill (ink or acid-lime, 3px border); progress bar (ink fill on paper, 2px border); horizontal scroll rails with round arrow buttons.
>
> **Pairing:** one backdrop, one card fill, one photo frame — each a different token, never two same-family colors touching. When in doubt, increase color contrast between adjacent layers.
>
> **Mood:** loud, joyful, Caribbean, high-contrast, sticker/vinyl-decal. Bold and maximal.
